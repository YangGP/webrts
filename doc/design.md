## 1. 概述

### 1.1 定位

模仿经典 RTS《蓝色警戒》（State of War, Cypronia, 2001）的 Web 即时战略游戏。保留其最核心的差异化设计——**"占领即生产"**：玩家没有传统建造系统，而是操控一艘核心飞碟去占领地图上的中立/敌方建筑，占领后建筑自动为你生产单位。

### 1.2 设计支柱

| 支柱       | 说明                                              |
| ---------- | ------------------------------------------------- |
| 占领即生产 | 唯一的生产途径是占领建筑，飞碟是全局命脉          |
| 决策制胜   | 弱化微操（APM），强调扩张/防守/兵力分配的宏观决策 |
| 快节奏     | 单局 15~25 分钟，无冗长发育期                     |
| 兵种克制   | 坦克/防空/远程/空中构成克制链，混编才能取胜       |

### 1.3 平台与技术约束

- 纯浏览器运行，桌面端为主（键鼠操作），暂不考虑移动端
- 技术栈：Vue 3 + TypeScript + Vite（已搭建）
- 渲染：Canvas 2D（俯视角），游戏逻辑与 UI 框架解耦

## 2. 世界观与背景

2020 年，七洲联盟建立的"超脑"全球防御系统被宗教势力**水晶兄弟会（Beho-Sunns）**入侵控制，22 个军事基地沦陷。玩家扮演同盟军团指挥官，驾驶核心指挥飞碟逐个夺回基地。

> v1 不做剧情演出，背景仅用于关卡命名与开场文案。

## 3. 核心玩法循环

```
 探索地图 → 发现中立建筑 → 派飞碟占领 → 建筑自动产兵
      ↑                                        ↓
 混编部队 ←—— 飞碟升级建筑 + 研究点解锁兵种 ←—— 获得资源（金矿/电力/研究点）
      ↓
 进攻敌方据点 / 防守己方建筑（敌 AI 会反扑占领）
```

- **胜负条件**：占领地图上所有敌方/中立核心建筑（指挥部）即胜利；己方所有指挥部被敌方占领则失败（飞碟被击毁仅损失生产力，30 秒后重生，不构成失败）。
- **单局时长目标**：15~25 分钟。

## 4. 核心系统

### 4.1 飞碟（玩家核心单位）

| 属性 | 数值（初版）                                                                                  |
| ---- | --------------------------------------------------------------------------------------------- |
| HP   | 800（可随关卡成长）                                                                           |
| 移动 | 全图自由飞行，无视地形                                                                        |
| 占领 | **攻击建筑**（必须停留在建筑正上方攻击，期间不可移动），血量清零即占领；对满血中立建筑约 30 秒                |
| 武器 | 专用炮（炮弹追踪必中）：攻击空中单位（敌飞碟/空袭编队）、防空坦克、以及**正下方的建筑**；伤害固定（不做成长） |
| 重生 | 被击毁后 30 秒在己方最后指挥部重生，期间无法生产                                              |

**武装规则**：

- 飞碟移动速度固定（不随关卡/升级变化）：**1s/格（20px/s）**，全图自由飞行、无视地形；
- 飞碟配备专用炮，**炮弹追踪目标、必定命中**（弹道速度固定），可攻击目标为：**空中单位**（敌方飞碟、空袭编队）、**防空坦克**（唯一的可攻击地面单位）、**建筑**（**必须停留在建筑正上方才能攻击，持续攻击期间不可移动——离开即中断**，伤害持续扣除建筑血量，清零即占领——这就是飞碟的占领方式）；
- 对防空坦克之外的地面单位**无法开火**（其他地面战斗必须由己方部队执行）；
- 伤害为固定值，不随关卡/升级成长；
- **伤害基准**：2 次攻击消灭 1 辆初级防空坦克（即初级防空坦克 HP = 2 × 飞碟单发伤害，以此为数值锚点）；对建筑的单发伤害另设独立数值（目标：打空满血中立建筑约 30 秒）；
- 飞碟能打防空坦克的设计意图：防空坦克是飞碟的天敌（对空火力），飞碟必须拥有反制窗口，否则防空坦克成为飞碟的绝对克制而无解。

**目标选择优先级**（自动索敌规则）：

1. **敌方飞碟**（最高优先，触发 MAD 对决）；
2. 敌方空袭编队；
3. 威胁范围内的敌方防空坦克。

- 以上为**默认索敌顺序**（范围内同时出现多个目标时的自动开火选择），玩家可随时下达移动指令**手动覆盖**（撤退/停火），飞碟不会被迫卷入 MAD 对决；
- **逃跑规则**：飞碟可主动撤退脱离交战，但双方飞碟移速相同——逃得掉一次交火，甩不掉执意追击的敌方飞碟（距离无法拉开，MAD 风险始终存在）；
- 飞碟对防空坦克之外的地面单位无威胁，飞碟与地面部队的交战界面清晰：**防空坦克打飞碟，飞碟反打防空坦克**，其余互不干涉。

**飞碟对决（MAD 机制）**：

- 两方飞碟互相攻击时，**同时被摧毁**（相互确保摧毁）；
- 实现规则：当 A 方飞碟的炮弹命中 B 方飞碟、且 B 方飞碟也已锁定 A 并开火（或弹道已在途中）时，双方立即同时阵亡；
- 战术含义：
  - 飞碟对决没有"操作取胜"空间，先手偷袭（对方未开火时击落）是唯一优势情形；
  - 用己方飞碟换掉敌方飞碟是可行的战术交换（换取对方生产力中断 30 秒）；
  - 遇 MAD 风险时主动撤退是可行的自保手段（但甩不掉执意追击的敌方飞碟，见上方逃跑规则）。

**规则**：

- 飞碟同一时间只能占领（攻击）或解锁升级一个建筑；
- **占领即攻击（已定案）**：飞碟占领 = 停留在建筑正上方持续攻击（期间不可移动），建筑血量清零即易主（与部队武力夺取统一为同一规则：**清零=占领**）；
- 玩家建造的防御塔**不可被占领**、只能被摧毁（金币投资不会被白嫖）；
- 飞碟被摧毁 = 生产力中断，是全局最大风险点（敌方飞碟的 MAD 对决、防空火力是主要威胁）。

**建筑升级（已定案）——统一机制**：

- 所有功能建筑均由**飞碟停留在上方读条升级**（**每级 20 秒**），不消耗任何资源（指挥部不可升级，仅为胜负判定点）；
- 升级的唯一成本是**飞碟时间**；受击不打断（飞碟被摧毁才中断）；
- 建筑等级效果是**数值增强**（生产速率/产出/射速等，见下表），等级本身**不解锁新兵种**。

**兵种解锁（已定案）——独立机制，消耗研究点数**：

- 生产建筑（兵营、战车工厂）升级到 2 级/3 级后，还需**花费研究点数解锁**对应的高级兵种；
- 升级（飞碟时间）与解锁（研究点数）相互独立、缺一不可：**2 级建筑 = 飞碟升级到 2 级 + 花研究点解锁中级兵种**；
- 未解锁时建筑按低级兵种表继续生产，解锁后自动切入高级兵种循环；
- 解锁与**建筑绑定**（打掉这座建筑重新占领后需重新解锁），与**阵营无关**；

| 解锁项                        | 前置条件      | 研究点数消耗 |
| ----------------------------- | ------------- | ------------ |
| 兵营·中级兵种（机器人强化型） | 兵营 2 级     | 15 点        |
| 兵营·高级兵种                 | 兵营 3 级     | 30 点        |
| 工厂·中级坦克                 | 战车工厂 2 级 | 15 点        |
| 工厂·高级坦克                 | 战车工厂 3 级 | 30 点        |

- 建筑等级上限 **3 级**，效果随等级线性提升：

| 建筑类型        | 升级效果                                                                    |
| --------------- | --------------------------------------------------------------------------- |
| 兵营 / 战车工厂 | 生产速率 +50%/级                                                            |
| 金矿            | 产出 +50%/级                                                                |
| 太阳能搜集器    | 电力供给 +50%/级                                                            |
| 研究实验室      | 研究点数产出 +50%/级                                                        |
| 空军基地        | 空袭点数积攒速率 +50%/级                                                    |
| 防空炮          | 射速 +30%/级                                                                |

- 建筑失守后等级**重置**（重新占领从 1 级开始，敌方 AI 同理）——攻防拉锯的代价真实存在；
- 升级节奏：**升级 = 飞碟时间**（20 秒/级），**解锁高级兵种 = 研究点数**（独立付费）；研究点数花在哪座建筑、先解锁哪个兵种是核心经济决策。

### 4.2 资源系统

| 资源           | 来源                     | 用途                                              |
| -------------- | ------------------------ | ------------------------------------------------- |
| **资金（金）** | 占领金矿后持续产出       | 购买防御塔（**唯一用途**）                        |
| **电力**       | 占领太阳能搜集器         | 每电力 +10% 单位生产速度与研究点数生产速度 |
| **研究点数**   | 占领研究实验室后持续产出 | 解锁生产建筑的高级兵种（兵营/战车工厂，15/30 点） |

- 占领金矿后每 2 秒产出 10 金，产出速率随占领数量线性叠加；
- **电力**：占领太阳能搜集器后持续供给电力（产出数值待定），**每 1 电力使单位生产速度与研究点数生产速度各加快 10%**（线性叠加，如 5 电力 = +50%）；无电力时均为基础速率（**不存在"电力不足惩罚"**，电力只加速、不减益——鼓励抢占电力点但零电力不瘫痪）；
- **研究点数**：占领**研究实验室**后每 5 秒产出 1 点（基础速率），产出速率随实验室等级（+50%/级）与电力（每 1 电力 +10%）提升，多座实验室叠加；实验室失守则停止产出（已积攒的研究点数保留）；
- 研究点数是**全局共享**的稀缺资源，唯一用途是**解锁高级兵种**（升级建筑本身免费，只花飞碟时间）；
- **单位生产无任何资源消耗**（v1 已定案），产能仅由生产建筑数量与电力决定；玩家通过**占领更多工厂/兵营**来增加并行生产队列。

**全自动生产（已定案）**：

- 生产队列**全自动**运行：**不消耗任何资源**、无需扣款，玩家不可暂停、不可调整队列顺序；
- 玩家对生产的影响手段只有一个——**占领或失去生产建筑**（这是"占领即生产"设计的自然延伸，把经营压力全部转化为地图控制权争夺）；
- 各建筑有独立的内置循环队列（如兵营按 步兵→机器人→步兵 循环），基础产能速率由电力加成提升（每 1 电力 +10%）。

### 4.3 建筑体系

**地图预置建筑**（占领获取，不可新建）：

| 建筑         | 功能                                           | 备注            |
| ------------ | ---------------------------------------------- | --------------- |
| 指挥部       | 核心建筑，胜负判定点（不可升级）               | 每图 2~4 个     |
| 兵营         | 自动生产步兵/机器人；升级+研究点解锁高级兵种   | 便宜、产能快    |
| 战车工厂     | 自动生产五型坦克；分初级/中级/高级三档（决定升级上限）；升级+研究点解锁高级坦克 | 主力产能        |
| 空军基地     | 积攒空袭点数、解锁空袭召唤                     | 见 4.5 空袭系统 |
| 金矿         | 持续产出资金                                   | 必争点          |
| 太阳能搜集器 | 产出电力                                       | 产能保障        |
| 研究实验室   | 持续产出研究点数                               | 兵种解锁必需    |
| 防空炮       | 预置防御建筑，拦截空袭编队与飞碟               | 守卫关键区域    |

**可建造建筑——防御塔（已定案）**：

玩家唯一的建造手段，使用**金币购买**：

| 防御塔 | 价格   | 功能                       |
| ------ | ------ | -------------------------- |
| 对地塔 | 200 金 | 自动攻击范围内敌方地面单位 |
| 防空塔 | 150 金 | 自动攻击敌方飞碟与空袭编队 |

**部署规则**：

- **只能部署在己方建筑一定范围内**（半径 5 格，以任一己方建筑为圆心）；
- 单座己方建筑周边最多部署 3 座防御塔（防塔海）；
- 支付金币后 10 秒建造完成（建造中可被攻击摧毁，金币不返还）；
- 防御塔**不可被占领**、只能被摧毁：可被地面部队（榴弹炮远程拆塔为首选）摧毁，也可被飞碟停留在上方攻击至血量清零（清零即**摧毁**，不适用"清零=易主"规则；杜绝"白嫖"玩家金币投资）；
- 己方建筑失守后，其周边防御塔保留并继续战斗（v1 简化：塔独立存在直到被摧毁）。

**战术定位**：

- 防御塔是金币的**主动防御性消费**（与空袭点数的进攻性形成对照）；
- 补齐指挥制下"无法微操防守"的空缺：用金币在关键位置固化防御力量；
- 占领新建筑 = 扩大防御塔可部署范围，进一步强化"占领即生产"的扩张激励。

**占领规则**（统一规则：**血量清零 = 易主**）：

- 所有地图预置建筑均有血量（含防空炮）；部队不会攻击己方建筑（同阵营不互射）；
- **飞碟占领 = 攻击**：飞碟停留在建筑正上方持续攻击（期间不可移动），清零即易主（对满血中立建筑约 30 秒，敌方建筑因战斗损伤往往更快）；
- **部队武力夺取**：部队将敌方/中立建筑血量清零 → 建筑立即易主（血量回复至满值），**不是摧毁**；
- 建筑易主后等级重置（重新从 1 级开始）；
- 敌方 AI 同样会派兵/飞碟抢占中立和己方建筑（核心压力来源）。

**统一规则的设计意图**：

- 占领逻辑全局只有一条（清零=易主），实现简单、心智清晰；飞碟与部队夺取的区别仅在**伤害来源**（飞碟需在建筑上方，部队在地面）；
- 建筑血量成为"占领进度条"：血量被打掉多少 = 距离易主多近，攻守双方都可读；
- 升级需要飞碟解锁（门闩）+ 研究点数（钥匙），飞碟的时间不再被长读条占用。

### 4.4 单位体系与克制链

**没有可生产的空中单位**（已定案）：空中的威胁只有双方的飞碟和召唤而来的空袭编队，空中打击能力全部由空袭系统（4.5）承担。

**地面单位**：

- **兵营生产**：

| 单位   | 定位           | 克制 | 被克制           |
| ------ | -------------- | ---- | ---------------- |
| 步兵   | 便宜填线、占点 | 无   | 一切范围伤害     |
| 机器人 | 高攻低防突击   | 坦克 | 防御塔群、步兵海 |

- **战车工厂生产（坦克体系）**：

**工厂档位（已定案）**：战车工厂分为**初级 / 中级 / 高级**三档（**地图预置属性，不可改变**），档位同时决定该工厂**可升级的等级上限**与**初始解锁的兵种等级**：

| 工厂档位 | 可升级上限 | 初始解锁 | 说明               |
| -------- | ---------- | -------- | ------------------ |
| 初级工厂 | 最高 2 级  | 1 级坦克 | 基础产能           |
| 中级工厂 | 最高 3 级  | 2 级坦克（免研究点） | 中期核心争夺点     |
| 高级工厂 | 最高 3 级（升级耗时 -25%） | 3 级坦克（免研究点） | 稀缺，通常重兵把守 |

- **初始解锁 = 出生自带的兵种等级**：中级/高级工厂被占领后**立即可以生产对应等级的坦克**，无需花研究点数解锁（研究点解锁是给低档工厂"补课"用的）；
- 抢夺高级工厂 = 直接获得 3 级坦克产能（快但有代价：重兵把守、且夺取后等级重置需重新升级爬楼）；
- 地图设计通过工厂档位分布控制战局节奏：初级工厂普及（基础产能）→ 中级工厂争夺（中期目标）→ 高级工厂决战（终局焦点）。

**高级坦克解锁（已定案）**：五型坦克均由战车工厂生产。获得高等级坦克有**两条路径**：

| 坦克等级 | 路径 A：占领自带 | 路径 B：低档工厂补课 |
| -------- | ---------------- | -------------------- |
| 1 级坦克 | 初级工厂初始即有 | —（基础五型：普通/火焰/榴弹炮/防空/激光） |
| 2 级坦克 | **中级工厂初始自带**（免研究点） | 工厂升至 2 级 + 15 研究点解锁 |
| 3 级坦克 | **高级工厂初始自带**（免研究点） | 工厂升至 3 级 + 30 研究点解锁 |

- **坦克等级 = 出生锁定**：坦克属性由产出工厂当时可产的等级决定，不会后天成长；
- 解锁**与建筑绑定**：工厂被夺取后等级重置、研究点解锁失效（档位自带的初始解锁跟随档位保留），敌方需自己升级并花研究点数重新解锁；
- 工厂实际等级上限 = **工厂档位上限**；
- **三条成长路径的分工**：档位 = 硬件天花板 + 出生自带的初始兵种（抢好工厂即用）；飞碟升级 = 在天花板内爬楼；研究点解锁 = 给低档工厂补课、或失而复得后恢复——抢与升与研，三线并行。

**五型坦克**：

| 坦克类型 | 定位与特性                                                               | 克制                                     | 被克制                           |
| -------- | ------------------------------------------------------------------------ | ---------------------------------------- | -------------------------------- |
| 普通坦克 | 正面主力、高甲均衡；**1 级：攻击 10 / HP 100**；**移速 2s/格（10px/s，速度锚点）** | 机器人、步兵                             | 榴弹炮、防御塔、火焰坦克（近身） |
| 火焰坦克 | **弹道穿透 + 持续低伤害**（火焰沿直线持续喷射，对弹道上所有单位持续造成低伤害），**攻击距离略近**，需贴脸输出 | 步兵海、机器人集群                       | 普通坦克（对拼吃亏）、榴弹炮远程 |
| 榴弹炮   | **超远程**火力、**脆皮**（HP 低于普通坦克一半）                          | 普通坦克、建筑、防御塔                   | 一切近战突击、火焰坦克贴脸       |
| 防空坦克 | 对空专用、**飞碟天敌**                                                   | 飞碟、空袭编队                           | 飞碟（2 发被消灭）、所有地面单位 |
| 激光坦克 | **单次高伤害**（充能后发射高能激光，单发高额伤害），**攻击距离最近**     | 长时间对峙的高价值目标（防御塔、榴弹炮） | 一切近战突击、被快速集火         |

**坦克等级成长（已定案）——适用于五型坦克**：

| 等级 | 成长方向                         | 说明                        |
| ---- | -------------------------------- | --------------------------- |
| 2 级 | **血量大幅提升、攻击略微提升**   | 中级坦克 = 更耐揍的前排     |
| 3 级 | **血量、攻击同步大幅提升**       | 高级坦克 = 全面强化的精锐   |

- 成长倍率（已定案）：**2 级 = HP ×1.8 / 伤害 ×1.2；3 级 = HP ×2.5 / 伤害 ×2.0**；
- 坦克等级 = 出生锁定（见工厂档位制），等级成长只在**生产时刻**生效于属性初值。

**五型坦克基础数值表（1 级，单位 px / tile = 20px）**：

| 属性           | 普通坦克   | 火焰坦克        | 榴弹炮           | 防空坦克        | 激光坦克       |
| -------------- | ---------- | --------------- | ---------------- | --------------- | -------------- |
| HP             | 100        | 80              | 45               | 100（锚点）     | 70             |
| 伤害           | 10/发      | 6/秒（持续）    | 25/发（溅射）    | 50/发（仅对空） | 35/发          |
| 攻击间隔       | 1.5s       | 持续喷射        | 3.0s             | 1.0s            | 2.5s（充能）   |
| 射程           | 60px（3格）| 40px（2格）     | 160px（8格）     | 140px（7格，对空）| 40px（2格）  |
| 移速           | 10px/s（2s/格） | 10px/s（2s/格） | 6px/s（3.3s/格） | 10px/s（2s/格） | 10px/s（2s/格） |
| 大小           | 1×1 地块   | 1×1 地块        | 1×1 地块         | 1×1 地块        | 1×1 地块       |

- **溅射（榴弹炮）**：以命中点为圆心半径 1 格（20px）内的所有敌方单位受伤；
- **持续喷射（火焰）**：按每秒结算，对火焰直线（长 2 格）上所有敌方单位每秒扣血；
- **对空专用（防空）**：只能攻击空中目标（飞碟/空袭编队），对地面目标无法开火；
- **对建筑伤害**：均等于自身伤害值，另乘克制系数（榴弹炮克制建筑 = ×1.5~2）。

**等级数值总表（HP / 单发伤害）**：

| 类型     | 1 级        | 2 级（HP×1.8 / 伤×1.2） | 3 级（HP×2.5 / 伤×2.0） |
| -------- | ----------- | ------------------------ | ----------------------- |
| 普通坦克 | 100 / 10    | 180 / 12                 | 250 / 20                |
| 火焰坦克 | 80 / 6 每秒 | 144 / 7 每秒             | 200 / 12 每秒           |
| 榴弹炮   | 45 / 25     | 81 / 30                  | 112 / 50                |
| 防空坦克 | 100 / 50    | 180 / 60                 | 250 / 100               |
| 激光坦克 | 70 / 35     | 126 / 42                 | 175 / 70                |

**数值自洽性推演**：

- 普通坦克对拼：1 级互相 10 发（15s）；3 级互相 12.5 发（~19s）——等级越高消耗战越长，符合"高级=精锐"；
- 激光 vs 普通（1 级）：激光 3 发（7.5s）击毁普通坦克，普通坦克需 7 发（10.5s）击毁激光——激光近战点杀占优，但需先顶着 2 格射程差接近；
- 火焰 vs 步兵海：每秒 6 伤 × 穿透一列，10s 烧穿 60HP 步兵队列——清集群定位成立；
- 防空 vs 飞碟：1 级防空 DPS 50 × 克制 1.5 = 75/s，单辆 11s 击落 800HP 飞碟；飞碟需 2 发（2s）点掉 1 辆防空坦克——"天敌但有反制窗口"成立；
- 榴弹炮：射程 8 格 vs 普通坦克 3 格，3 发（9s）击毁 1 级普通坦克，但 HP 45 被普通坦克 5 发带走——远程压制但极度怕近身，符合"最脆"。

**坦克体系设计要点**：

- 五型坦克构成"距离-伤害"谱系：**激光（最近/单发高伤）→ 火焰（近/穿透持续）→ 普通（中/均衡）→ 防空（中/对空）→ 榴弹炮（最远/最脆）**；
- 榴弹炮是唯一远程拆建筑/塔的手段，但需要前排保护；激光坦克是近距离点杀高价值目标（防御塔/榴弹炮）的利器，但射程吃亏、怕被集火；
- 全自动生产下，玩家通过**占领更多战车工厂**（并行队列）而非选兵种来影响兵种结构（各工厂内置循环队列覆盖全部五型）。

**克制数值原则**：被克制方受到 1.5~2 倍伤害，克制方受到 0.6 倍伤害。

### 4.5 空袭系统（召唤制）

**没有可操控的空军单位**，空袭是"占领空军基地 → 积攒点数 → 召唤空袭"的技能系统：

**点数积攒**：

- 每占领一座空军基地，每 3 秒自动获得 1 点空袭点数（多座基地叠加积攒速率）；
- 失去空军基地则停止积攒（已积攒的点数保留）；
- 点数上限 20 点，防止无限囤积。

**空袭类型**（v1 提供三种；侦察空袭已移除——**无战争迷雾，全图可见**，无侦察需求）：

| 空袭     | 消耗  | 效果                                                                 | 反制手段                     |
| -------- | ----- | -------------------------------------------------------------------- | ---------------------------- |
| 精准轰炸 | 5 点  | 对单一目标投放精确制导弹，**单体高额伤害**（对建筑全额伤害，适合拆塔/点杀） | 防空炮拦截、飞碟拦截         |
| 大范围轰炸 | 10 点 | 对目标区域投弹，**大范围高额伤害**（对建筑减半，适合清兵海）          | 防空炮拦截、飞碟拦截         |
| 空投作战单位 | 15 点 | 运输编队向目标区域空投一批作战单位（编队落地后转为 AI 托管地面部队，按集结点规则行动） | 防空炮拦截、飞碟拦截（击落则单位落空） |

**召唤规则**：

- 玩家点击 HUD 空袭按钮 → 选择目标点 → 编队从最近的己方空军基地起飞，沿直线飞向目标；
- 空袭编队是**一次性的不可控实体**（非单位）：轰炸编队到达目标投弹后返场消失；空投编队投下单位后返场消失，落地单位即刻加入己方部队（AI 托管，遵循集结点规则）；
- 空袭编队飞行途中可被**防空炮**（优先目标）和**飞碟**（反空炮）击落，击落则空袭落空、点数白费；
- 敌方 AI 使用相同的空袭系统（AI 的空袭偏好打击玩家建筑密集区）。

**战术定位**：

- 空袭 = 花费时间（占基地攒点）换来的战略打击，而非即时操作；
- 三种空袭的分工：**精准轰炸**点杀高价值目标（防御塔/榴弹炮/关键建筑）、**大范围轰炸**清剿集结兵力、**空投作战单位**开辟敌后第二战线（绕过地面防线直插腹地）；
- 防空炮因此成为守卫要地的核心防御，反空袭博弈（诱导敌方空袭到防空密集区）是高阶玩法。

### 4.6 升级系统（简化版）

- **单位升级 = 工厂档位制**（v1 已定案）：坦克等级由产出工厂的档位决定（初级=1 级/中级=2 级/高级=3 级），出生锁定、不可后天升级；
- **建筑升级 = 飞碟升级制**：见 4.1 建筑升级规则（上限 3 级，每级 20 秒）；
- 原设计"按累计生产数量升级单位"已废弃（与出生锁定冲突，且工厂档位制已提供质量成长曲线）；
- 空袭点数积攒速率不参与升级；v1 不做分支科技树。

### 4.7 敌方 AI（v1 简化）

- 状态机：`防守 → 试探扩张 → 抢占中立点 → 集团进攻`；
- AI 拥有自己的飞碟、生产建筑与空军基地，遵循与玩家完全相同的规则（含空袭点数积攒、防御塔购买）；
- 难度分级（3 档）调整：AI 初始部队规模、扩张频率、资源加成。

## 5. 操作设计（Web 键鼠，指挥制）

**操作理念（已定案）——指挥制**：玩家扮演的是"军团指挥官"而非"操作员"。除飞碟外**不能选中/操控单个作战单位**，部队行为完全由 AI 自动执行，玩家只下达宏观指令。

### 5.1 可下达的指令类型

| 指令对象     | 可下达指令                                                                                | 说明                             |
| ------------ | ----------------------------------------------------------------------------------------- | -------------------------------- |
| **飞碟**     | 完全可控：移动、攻击目标、占领建筑                                                        | 唯一可直接操控的实体             |
| **集结点**   | 设置/移除多个集结点；各生产建筑可绑定不同集结点                                           | 见 5.2 多集结点机制              |
| **生产建筑** | 单独指令：设定集结点绑定 / 调整出兵倾向（如"防御模式"驻守周边 vs "进攻模式"随集结点推进） | 兵营/战车工厂可各自下达         |
| **空袭**     | 选目标点召唤（B/N/M）                                                                    | 见 4.5                           |

### 5.2 多集结点机制（已定案）

- 玩家可在地图上设置**多个集结点**（v1 上限 8 个，可随时增删）；
- 新产出的单位**自动选择距离最近的集结点**作为目标（按生产建筑位置计算直线/路径距离）；
- 每个生产建筑可**绑定指定集结点**（覆盖"最近"逻辑，用于定向支援某条战线）；
- 移除集结点后，原本趋向它的部队按"最近"规则自动重新分流到其余集结点；全部移除时回退为驻守所属建筑。

**部队自动行为（AI 托管）**：

- **无集结点时**：部队驻守其所属建筑周边（防守半径），自动攻击进入范围的敌人；
- **有集结点时**：部队自动向绑定的集结点移动，途中遇敌自动交战（攻击-移动），到达后转入驻守；
- **威胁响应**：己方建筑受攻击时，附近部队自动增援（无需玩家操作）；
- 玩家**不能**框选单位、不能指定攻击目标、不能控制单个单位的移动。

### 5.3 键鼠操作表

| 操作                   | 行为                                                                  |
| ---------------------- | --------------------------------------------------------------------- |
| 左键点击飞碟           | 选中飞碟（唯一可选中单位）                                            |
| 右键（选中飞碟时）     | 移动 / 攻击目标 / 占领建筑                                            |
| Shift + 左键点击空地   | **添加集结点**（画布/小地图均有效）                                   |
| 点击已有集结点         | 选中集结点（可删除、可绑定生产建筑）                                  |
| 左键点击己方生产建筑   | 打开建筑指令面板（绑定集结点/攻防倾向）                               |
| 空格                   | 跳转最近警报（己方建筑被攻击）                                        |
| B / N / M               | 召唤精准轰炸 / 大范围轰炸 / 空投作战单位（进入目标点选模式） |
| T / Y                  | 购买对地塔 / 防空塔（进入部署点选模式，仅高亮己方建筑范围内有效区域） |
| ESC                    | 取消空袭/防御塔点选 / 取消选择                                        |
| 小地图点击             | 移动镜头；Shift+点击 添加集结点                                       |
| 滚轮 / WASD / 屏幕边缘 | 镜头控制                                                              |

**由此简化的内容**：无编队系统（`1~9`）、无单位框选、无单位微操；寻路与战斗全部自动。

**设计收益**：

- 把 RT S的 APM 门槛降为零，胜负完全取决于**战略决策**（往哪集结、占哪个点、何时换家）；
- 与"占领即生产""全自动生产"共同构成纯指挥层体验，三条设计一脉相承。

## 6. 关卡结构

- v1 提供 **3 张关卡**（战役第一章）：
  1. **夺回前哨**：教学关，1 个敌方指挥部，无空袭；
  2. **金矿争夺**：中立金矿密集，AI 高频抢占；
  3. **要塞攻坚**：敌方重防+拥有空军基地（会召唤空袭），需防空炮掩护推进。
- 地图统一划分为**地块（tile）**，每块 **20×20px**；**所有初级单位大小均为 1 个地块**（20×20px）。
- 每关地图尺寸约 64×64 格（1280×1280px，tile 20px，画布 1280×720 需镜头滚动）。
- 部分关卡有**时间锁**：超时后敌方无限增援（还原原作压力感，v1 第 3 关启用）。

## 7. 技术方案

### 7.1 架构分层

```
src/
├── game/                  # 纯 TS 游戏引擎层（不依赖 Vue）
│   ├── core/              # 游戏循环、事件总线、指令系统
│   ├── ecs/               # 实体-组件（Unit/Building/Projectile 轻量实现）
│   ├── systems/           # 移动寻路、战斗、生产、占领、AI、资源
│   ├── map/               # 地图数据、tile、寻路网格
│   └── render/            # Canvas 2D 渲染器、镜头、特效
├── ui/                    # Vue 组件（Hud、菜单、编队面板）
├── stores/                # Pinia：UI 状态（选中、资源快照）
└── levels/                # 关卡数据（JSON）
```

**关键决策**：

- 游戏逻辑用固定时间步长（60Hz）更新，渲染插值，与 Vue 响应式完全隔离（性能考虑，单位数可达 200+）；
- Vue 只负责 HUD/菜单，通过事件总线 + Pinia 快照读取游戏状态（每帧节流同步）；
- 寻路：网格 A\*（v1 不做流场，单位间碰撞用简单推挤分离）；
- 不引入渲染引擎依赖，MVP 用 Canvas 2D + 程序化图形，**美术方向采用几何图形风（已定案）**：
  - 单位 = 基本几何形状组合（如坦克=矩形车体+圆形炮塔、飞碟=椭圆+光圈、步兵=小圆点）；
  - 阵营用颜色区分（玩家蓝、敌方红、中立灰），单位类型靠形状+图标区分；
  - 特效走简约路线：纯色描边爆炸圈、渐隐弹道线；
  - 后续如需升级美术，仅替换渲染层图形定义，不影响游戏逻辑。

### 7.2 性能预算

- 同屏单位 ≤ 300，逻辑帧 ≤ 2ms，渲染帧 ≤ 8ms（60fps）。
