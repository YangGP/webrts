## 1. M1 最小数值表（开发用初版，单位 px/tile）

### 1.1 飞碟

| 属性         | 数值 | 说明                                      |
| ------------ | ---- | ----------------------------------------- |
| HP           | 800  | M1 无对空威胁，仅被中立/敌方防空炮攻击    |
| 移速         | 20   | px/s（**1s/格**，1 tile/s）               |
| 对建筑伤害   | 30   | 单发；攻击间隔 1.0s                       |
| 对空伤害     | 50   | 单发（锚点：初级防空坦克 HP = 100 = 2 发） |
| 炮弹速度     | 400  | px/s（= 20 tile/s），追踪必中（命中时刻按飞行距离计算） |
| 攻击范围     | —    | 对建筑：**必须停留在建筑判定区正上方，持续攻击期间不可移动**（离开即中断）；对空 120px（6 tile） |

### 1.2 兵营

| 属性       | 数值 | 说明                                          |

| HP         | 900  | 飞碟 DPS 30 → 打空满血恰好 30s（对齐锚点）    |
| 占地       | 3×3  | tile（60×60px），判定区 = 占地外扩 0.5 tile |

| 出兵点     | 占地边缘最近的可通行格 | —                             |

### 1.3 地面单位

**单位大小**：所有地面单位均为 **1×1 地块（20×20px）**（含后续的初级坦克）。

| 属性       | 步兵   | 机器人 |
| ---------- | ------ | ------ |
| HP         | 60     | 100    |
| 攻击伤害   | 8      | 15     |
| 攻击间隔   | 1.0s   | 1.2s   |
| 射程       | 60px（3 tile） | 60px（3 tile） |
| 移速       | 8px/s（2.5s/格） | 10px/s（2s/格，与普通坦克同速） |
| 碰撞半径   | 8px    | 10px   |
| 对建筑伤害 | 同攻击伤害 | 同攻击伤害 |

> 推演：10 个步兵 DPS ≈ 80 → 打空满血兵营（900 HP）约 11s；飞碟单人占领 30s。集团夺取快于飞碟，符合"部队武力夺取"定位。
> 坦克数值：五型坦克（1/2/3 级）完整数值表见 GDD-v1.md 4.4 节"五型坦克基础数值表"与"等级数值总表"。

## 2. M1 测试关卡数据格式（levels JSON）

```json
{
  "id": "m1-test",
  "name": "M1 测试图",
  "size": { "w": 64, "h": 36 },
  "terrain": [],
  "buildings": [
    { "type": "command",  "faction": "player",  "x": 4,  "y": 15 },
    { "type": "barracks", "faction": "neutral", "x": 28, "y": 15 },
    { "type": "barracks", "faction": "neutral", "x": 52, "y": 15 }
  ],
  "spawn": { "x": 5, "y": 16 }
}
```

- `terrain`：M1 为空数组（全可通行）；M2 引入障碍格后存 tile 坐标列表；
- `x/y` 为建筑**左上角 tile 坐标**（占地由类型表决定，见 1.2）；
- `spawn` 为飞碟出生点（tile 坐标）。
